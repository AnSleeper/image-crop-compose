# 图片自由裁剪

一个 Windows 桌面图片小工具：从源图上**自由裁剪素材**（矩形 / 多边形 / 套索），再把素材**自由拼摆或自动排版**合并成一张大图，批量导出。纯 Python 实现，界面基于 Tkinter，图像处理基于 Pillow，无任何网络行为。

## 功能特性

### ① 裁剪素材
- **矩形 / 多边形 / 套索**三种裁剪方式
- 多边形、套索裁剪保留透明通道，形状以外区域导出为透明（4 倍超采样抗锯齿）
- 裁剪结果可加**白边 / 黑边**：矩形向外扩一圈纯色边框，不规则形状沿轮廓描边、形状外保持透明
- 滚轮缩放、中键平移、选区尺寸实时预览、后退键退掉上一个顶点

### ② 合成画布
- **自由模式**：素材拖拽摆放、缩放、90° 旋转、水平 / 垂直翻转、图层上下移；靠近其他元素或画布边缘时自动贴紧并显示辅助线
- **顺序拼接**：横向 / 纵向首尾相接，可调间距与对齐方式
- **网格模式**：行列数、间距、单元尺寸可自定义；适应 / 填充 / 拉伸 / 原始四种填充方式；素材多于格子数时自动分页导出
- 画布尺寸可调，背景支持透明或任意纯色，「贴合内容」一键收缩画布

### 其他
- Ctrl+Z 撤回（最多 50 步）
- 深色 / 浅色主题，设置自动记忆
- 图片可直接拖进窗口导入
- 导出 PNG / JPEG / WEBP，可选导出成品图和 / 或全部素材（JPEG 自动把透明区域压成白底）
- 绿色便携：设置保存在程序目录下的 `settings.json`，整个文件夹拷到别处设置依然跟着走

## 安装与运行

需要 Python 3.10+。

```bash
python -m pip install -r requirements.txt
python main.py
```

Windows 下也可以直接双击 `启动.bat`（会优先使用目录内 `.venv` 中的解释器）。

> `windnd`（Windows 拖拽导入支持）为可选依赖，未安装时其余功能不受影响。

## 打包

使用 PyInstaller 打包为单文件 exe：

```bash
python -m pip install pyinstaller
pyinstaller "图片自由裁剪.spec"
```

## 项目结构

| 文件 | 职责 |
|---|---|
| `main.py` | 启动入口，依赖检查 |
| `app.py` | 主窗口、素材库、导出对话框、设置持久化与撤回系统 |
| `views.py` | 可缩放平移的画布基类、裁剪视图、合成画布视图 |
| `model.py` | 数据模型：源图、裁剪素材、画布元素、合成文档 |
| `imaging.py` | 图像处理核心：裁剪、描边、拼接 / 网格排版、合成与导出（仅依赖 Pillow） |
